# 日本MMA戦績録（Japan MMA Record）

1989年の修斗旗揚げから現在まで、日本で行われた総合格闘技（MMA）の大会・試合・選手の記録を集めたデータベースです。
どなたでも無料で見られ、出典を明記すれば記録を自由に使えます（くわしくは [LICENSE-DATA.md](LICENSE-DATA.md)）。

- サイト: https://japan-mma-record.github.io/
- 作成者: 石井道場（株式会社石井道場）

## 中身

| フォルダ・ファイル | 内容 |
|---|---|
| `data/core/` | 記録の本体。`events.tsv`（大会）、`bouts.tsv`（試合）、`fighters.tsv`（選手）。表計算ソフトで開けるタブ区切りの文字ファイル |
| `data/auto/` | 公式サイトから毎日自動で取り込んだ新しい大会 |
| `data/fixes.tsv` | 個別の訂正（あれば） |
| `data/promotions.tsv` | 団体の表示名 |
| `build.py` | 記録からサイトを作るプログラム |
| `fetch.py`, `fetchers/` | 公式サイトから新しい結果と今後の大会予定を取り込むプログラム |
| `template/` | サイトの見た目（デザイン） |
| `.github/workflows/` | 毎日の自動更新と、年1回のデータ保存の設定 |
| `HANDOVER.md` | **後を引き継ぐ方へ**。仕組みと直し方 |

## 記録の決め方

- 勝敗・決まり手・時間は、各団体の公式記録と当時の報道（ゴング格闘技、BOUT REVIEW など）で確かめています。
- 推測では埋めません。勝敗がはっきり書かれた資料がない試合は空欄（勝敗不明）です。
- MMAの試合だけを収録しています。キック・グラップリングだけの試合や、子どもの試合は含めていません。
- 日本の資料がまだ見つかっていない一部の試合は、海外の記録サイトの記録を日本語に直して載せています。出典欄に「海外の記録サイト」とある大会です。

## 手元でサイトを作るには

Python 3 があれば、追加のインストールなしで動きます。

```
python3 build.py      # _site/ にサイトができる
python3 fetch.py      # 公式サイトから新しい結果を取り込む
```
